Neon Board is a fast, dark-neon, read-only make.fun frontend from plain static files: a live bounty board with live pots, entry fees and time left, bounty pages with live reward tables, leaderboards and public profiles, all from make.fun's public API. It revalidates API answers with minute-bound ETags (If-None-Match / 304), searches, filters and sorts the board without reloading, and works from any static server with no build step and no sign-in.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
